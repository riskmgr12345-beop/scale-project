# 저울 (Scale Project)

각 종목이 "오를 이유"(부스터: 거래량비, 최근 빠른반등 이력)와 "내릴 이유"(위험신호: 당일 급반등)를
저울질해서 순점수(-5~+5)로 계산하고, 코스피+코스닥 전체(약 2,700종목) 중 상위 후보를 뽑는
리서치 프로젝트입니다.

## 배경

V3(`stock-autotrading-v3`)의 ZZ 되돌림 전략에서 49종목/8년 데이터로 검증한 "줄다리기" 공식을
그대로 코스피+코스닥 전체에 적용했더니, 방향성(강한이김≥2점이 낫다)은 재현됐지만 절대 수치는
많이 달랐습니다(`scale_validation_result.txt` 참고). 그래서 같은 공식이라도 유니버스가 다르면
별도로 검증·관리해야 한다는 원칙 아래 "저울"이라는 별도 이름/프로젝트로 분리했습니다.

## 데이터 소스

`limitup-precursor-research`(콜라 프로젝트, https://github.com/riskmgr12345-beop/limitup-precursor-research)
가 매주 자동 갱신하는 `research_cache/limitup_ohlcv_cache.pkl`(코스피+코스닥 전체 OHLCV)을
읽기전용으로 재사용합니다. 이 저장소 자체는 시세 데이터를 직접 수집하지 않습니다.

## 파일

- `scale_validation_test.py`: 저울 공식(부스터-위험신호)이 코스피+코스닥 전체에서도 통하는지
  검증한 스크립트 (n=77,750, 강한이김/약한이김/비김/짐 4분류 + 시기분할 재현성 확인).
- `render_scale_report.py`: 상위 15개 종목을 뽑아 보고서(`scale_top15_report.txt`)를 생성하는
  본 프로덕션 스크립트.

## 검증 요약 (2026-09-04)

- 강한이김(≥2점): 5일도달률 72.8%, 5일째평균 +0.49%
- 약한이김(==1점): 65.3% / -1.10%
- 비김(0점): 52.8% / -3.20%
- 짐(<0점): 53.3% / -2.96%
- 시기분할(2025-11-19 기준 전/후반부) 둘 다 강한이김이 우위, 재현됨.

**주의**: "이김"을 넓게(점수>0 전체) 잡으면 평균이 -0.31%로 오히려 마이너스입니다.
반드시 ≥2점(강한이김) 기준으로만 걸러야 합니다.

## 향후 과제

- 종목현황(52주위치는 포함됨, 수급·PER·관리종목 여부는 미포함) 확장 -- 재무/투자자 데이터
  소스 추가 연결 필요.
- 관리종목/거래정지 임박 종목 필터링 검토.
- 클라우드 에이전트로 매일 자동 실행 + 보고.
- 생존편향(상장폐지 종목이 캐시에 없음) 미해결 -- 다음 검증 우선순위.

## 데이터 품질 이슈: 거래량 0인 날 (2026-09-04, 사용자가 확대차트 보고 직접 발견)

`엑사이엔씨`의 08-07 하루가 O=H=L=C=760원·거래량=0으로 찍혀있었는데, 전후일(08-06/08-10/08-11)은
전부 3,800원으로 완전히 동일했습니다(거래정지 등으로 실제 거래가 없던 날에 데이터공급사가
임의값을 채워넣은 것으로 추정). 이런 날을 진짜 가격으로 계산하면 지그재그/터치 로직이 가짜
대폭락(-80%)·급반등(+400%) "터치"를 만들어냅니다. `render_scale_report.py`에 `_drop_zero_volume_
days()`를 추가해 거래량<=0인 날을 시계열에서 통째로 제거(그 날 자체가 없었던 것처럼)하도록
고쳤습니다. **주의**: `scale_validation_test.py`(77,750건 백테스트)는 아직 이 필터를 안 씀 --
같은 종류의 가짜 터치가 검증 표본에 섞여있을 가능성이 있어 재검증이 필요합니다.
